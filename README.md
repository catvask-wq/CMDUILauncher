# CMDUILauncher
CMDVasilok — графическая оболочка для cmd.exe в стиле Total Commander на Python + PyQt6. Двухпанельная навигация по дискам и папкам с адресной строкой, поиском и историей переходов. Встроенный живой терминал с историей команд и автоперезапуском cmd. Умные ассоциации файлов: .bat, .py, .ps1 запускаются в терминале, текст и конфиги — в редакторе, остальное — по системной ассоциации. Контекстное меню, переименование, удаление, копирование путей, справка F1, тёмная тема, F5 — обновление. Просто запустите .bat
